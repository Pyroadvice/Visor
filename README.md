# Visor pirotécnico digital

Verificación de alturas de efectos pirotécnicos con la cámara del móvil,
medidas como porcentaje de la distancia de observación.

- `index.html` — aplicación de medida (foto, vídeo, directo, calibración)
- `nivel.html` — nivel e inclinómetro, diagnóstico de sensores

Herramienta de trabajo interno de Pyroadvice T.S. No sustituye a un
organismo notificado ni a un laboratorio de ensayo.
